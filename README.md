# Diary Bot

Telegram-бот «дневник»: пишете ему текстом, голосом или фото — он сохраняет записи, выделяет из них тезисы и собирает отчёты за день, неделю и месяц.

Попробовать: [@my_person_diary_bot](https://t.me/my_person_diary_bot)

## Возможности

- **Текст, голос, фото.** Голосовые распознаются локально через faster-whisper (large-v3, GPU), перед сохранением бот просит подтвердить расшифровку. Фото привязываются к подписи или к последующему рассказу.
- **Тезисы и отчёты.** Из каждой записи LLM (OpenRouter) выделяет тезисы; `/report` или кнопка «📊 Отчёт» объединяет их за день, неделю или месяц.
- **Несколько дневников.** Переключение кнопками, закреплённое сообщение показывает активный дневник.
- **Вопросы по расписанию.** Раз в день бот задаёт вопросы (текстовые и числовые), включаются и выключаются через `/questions on|off`.
- **Лимит слов.** 1500 слов в день бесплатно, дополнительные слова начисляет администратор (`/grant`); пользователь может запросить их кнопкой.

## Стек

Python 3.12, aiogram 3, PostgreSQL + SQLAlchemy (async) + Alembic, Redis + arq, faster-whisper, Docker Compose.

## Запуск

```bash
cp .env.example .env   # заполните BOT_TOKEN, OPENROUTER_API_KEY и пароль БД
docker compose up -d --build
docker compose exec bot alembic upgrade head
```

Воркеру транскрибации нужна NVIDIA GPU с поддержкой Docker (`--gpus`).
